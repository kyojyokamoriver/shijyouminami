駅ナカ南壁 外カメ・3人自撮り統合版

使い方
1. ZIPを解凍し、oni-integrated内のファイル・selfieフォルダ・assetsフォルダを、そのままHTTPSのWeb公開先へ置きます。
2. index.htmlを開くと外カメが自動で開きます。↻で内カメへ直接切り替わります。撮り方の選択画面は出ません。
3. カメラを許可します。切替ボタンで元の外カメに戻れます。
4. 顔検出の準備後、最大3人の頭上に1匹ずつ鬼が乗ります。1人では1匹、2人では2匹、3人では3匹です。
5. 髪の上に余白をあけて撮影してください。頭上が画面外の場合は顔や肩へずらさず、その人の鬼を隠します。顔が見えない時も鬼は隠れます。

変更点
・元の外カメの描画・妖怪の動き・影・写真/動画保存・指操作を保持。
・送付されたThree.js＋MediaPipeの内カメ版を統合。
・顔の最大3人検出、位置の平滑化と追跡、未検出時の消去。
・肩の鬼を廃止。鬼は頭上に限定し、顔をまたぐドラッグは無効。
・前後ともブラウザから端末のカメラ映像を取得。ズーム制御がある端末では1倍に設定。
・自撮りは映像全体を表示するため、映像比率によって余白が出ます。
・画面を切り替える時は前のカメラを停止し、前後同時に開きません。

注意
OS標準カメラアプリを起動する方式ではありません。鬼の合成とリアルタイム認識はブラウザ内で行います。
Webカメラの画角・画質はOS標準カメラアプリと完全には一致せず、レンズの最終選択は端末とブラウザによります。
送付された0バイトのdataファイルは同名の空ファイルで補っています。
顔検出・人物切り抜きのモデルを同梱しているため、CDNへのアクセスなしで読み込めます。
自撮りでは最初にモデルを読み込むため少し時間がかかります。
モデル読み込み完了後も鬼が出ない場合は、十分な明るさで3人全員の顔が見えるようにしてください。

検証
JavaScriptの構文、ローカルファイル参照、3人までの顔追跡、1→2→3→2→1→0人時の頭上配置、前後1倍設定を確認。
実際のスマホカメラ映像での3人同時検出、録画・共有の確認は未実施です。
開発用チェック: node checks/verify.mjs
